# 🤖 Groq AI Chat App

A full-stack AI chat application that generates responses using Groq API.
Built with a modern React frontend and Node.js backend.

---

## 🚀 Features

* 💬 Ask questions and get AI-generated responses
* ⚡ Fast API integration with Groq
* 🎨 Clean and responsive UI (Tailwind CSS)
* 🔐 Secure API handling using backend

---

## 🛠 Tech Stack

* **Frontend:** React (Vite), Tailwind CSS
* **Backend:** Node.js, Express
* **API:** Groq AI
